# IoT-Based ICU Patients Health Monitoring System

## 📌 Project Overview

This project explores the use of Internet of Things (IoT) technology for remote patient health monitoring in an Intensive Care Unit (ICU).

## 🎯 Objective

To demonstrate how connected devices can help collect and monitor patient health information and support timely medical attention.

## ✨ Key Features

- Remote health monitoring concept
- Collection of patient data using suitable sensors
- Display of health information on a monitoring interface
- Potential alerts for abnormal readings, depending on implementation

4. A monitoring interface presents the available information.
